# Start here (VS Code)

1. In VS Code, **File → Open Folder… → this folder** (`GRAIL_Collector_Complete_Final`).
2. Read **`15_Run_in_VSCode/README.md`**. Press ⌘⇧V to see it formatted.
3. Once only: in the VS Code terminal run `python3 15_Run_in_VSCode/run.py install-vscode`.
   This installs the task list.
4. Press ⌘⇧P → **Tasks: Run Task** → **0. Check setup**, then run the other tasks from the same list.

The task list comes from `15_Run_in_VSCode/vscode_config/`. All re-runs write only to
`15_Run_in_VSCode/work/`; the delivered results are never overwritten.
